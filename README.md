# Venta de garaje

Catálogo público gratuito con consulta de inventario en Google Sheets y contacto por WhatsApp.

La web está en `index.html`. Para activar GitHub Pages, entra a Settings → Pages, selecciona Deploy from a branch → main → / (root) → Save.

Para actualizar estados, precios y fotografías, modifica la hoja de Google Sheets asociada. La hoja debe compartirse como «Cualquier persona con el enlace: Lector» para permitir consultas públicas. Nunca agregues datos sensibles a esa hoja.

Las fotografías reales se incorporarán cuando estén disponibles.
